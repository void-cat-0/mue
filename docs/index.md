# Guide

| Step | Chapter | What you can do |
| --- | --- | --- |
| **Learn** | [Course contents][learn-index] | Follow the chapters in order. |
| 1 | [Your first window][getting-started-guide] | Open a window and mount a view. |
| 2 | [Reactive state and children][basics-guide] | Trace a signal write through a label and a retained child list. |
| 3 | [Layout, paint, and motion][style-guide] | Arrange boxes, style labels, and animate a bound value. |
| 4 | [Reusable views and custom nodes][components-guide] | Separate caller props, local state, and node hooks. |
| 5 | [Shared appearance][themes-guide] | Share typed palette values across a subtree. |
| 6 | [Screen navigation][scenes-guide] | Retain an editor under another screen and animate a stack change. |
| 7 | [Input routing][scene-input-guide] | Connect controls and raw keyboard input to the same command. |
| 8 | [Asynchronous work][tasks-guide] | Move file IO off the frame loop and publish results. |
| 9 | [Localized interfaces][i18n-guide] | Bind messages to the locale and reactive arguments. |
| **Apply** | [Build a release checklist][release-checklist-guide] | Combine a retained editor, shared preferences, shortcuts, and background file work. |
| **Look up** | [Reference contents][guide-reference] | Check syntax and runtime contracts at any point in the course. |
|  | [View and node authoring][components-reference] | Builder parameters, generated builders, node hooks, and modal controls. |
|  | [Reactive runtime and ownership][state-reference] | Signals and props, keyed children, ownership, and scope boundaries. |
|  | [Rendering and resources][paint-reference] | Background geometry, shadow admission and caching, render state, and texture lifetimes. |
|  | [Style declarations][style-reference] | All `style!` declarations, accepted values, units, transforms, and transitions. |
|  | [Scene runtime][scenes-reference] | Callbacks, input, scheduling, stack operations, faults, and effects. |
|  | [Theme store and context][themes-reference] | Typed lookup, snapshots, live bindings, and inheritance. |
|  | [Task executor][tasks-reference] | Handles, timing, cancellation, operation scopes, and worker threads. |
|  | [Fluent catalogs and bindings][i18n-reference] | Catalogs, bindings, fallback, diagnostics, and Fluent number formatting. |
|  | [Workspace examples][examples-guide] | Runnable programs in the workspace. |
