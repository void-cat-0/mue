# Localization

[Learn contents][learn-index]

The last step makes Focus speak more than one language. In this chapter you
move its text into [Fluent][fluent] message files, show messages that depend on
numbers (one session, three sessions), and switch between English and Chinese
while the app runs.

Enable the `i18n` feature of mue:

```toml
[dependencies]
mue = { git = "https://github.com/void-cat-0/mue", branch = "main", features = ["i18n"] }
```

## Messages in Fluent

Fluent keeps each language's text in its own file. A message has an ID, and can
take arguments and choose a form by number, which matters because languages
count differently. English needs "1 session" and "2 sessions"; Chinese uses one
form:

```text
# en-US/focus.ftl
start = Start
pause = Pause
sessions = { $count ->
    [one] { $count } session today
   *[other] { $count } sessions today
}

# zh-CN/focus.ftl
start = 开始
pause = 暂停
sessions = 今天完成了 { $count } 个专注时段
```

## Load the catalog

Add each file to a `CatalogBuilder`, build an `I18n` with a starting language,
and take a `Translator` for your messages. `tl!` binds a message, with its
arguments, to a label:

<div class="mue-demo">
<div class="mue-demo-code">

```rust
# #[cfg(feature = "i18n")]
# fn demo() -> Result<(), Box<dyn std::error::Error>> {
use mue::{i18n::{CatalogBuilder, I18n, langid, tl}, prelude::*};

let mut catalog = CatalogBuilder::new();
catalog.add_ftl(langid!("en-US"), "focus", r#"
start = Start
pause = Pause
sessions = { $count ->
    [one] { $count } session today
   *[other] { $count } sessions today
}
"#)?;
catalog.add_ftl(langid!("zh-CN"), "focus", r#"
start = 开始
pause = 暂停
sessions = 今天完成了 { $count } 个专注时段
"#)?;

let i18n = I18n::new(catalog.build()?, langid!("en-US"))?;
let focus = i18n.translator("focus")?;

let owner = OwnedScope::new();
let view = owner.run(|| {
    let count = signal(3_u32);
    let running = signal(false);
    let start = focus.text("start");
    let pause = focus.text("pause");
    vstack().gap(12.).style(style! { align-items: center; }).children((
        text(tl!(focus, "sessions", "count" => count.get()))
            .style(style! { font-size: 20px; color: #2d2a26; }),
        button(running.pick(pause, start))
            .on_activate(move || running.update(|on| *on = !*on)),
    ))
});
# let _ = view;
# Ok(())
# }
# #[cfg(feature = "i18n")]
# demo().unwrap();
```

</div>
<figure class="mue-demo-preview mue-focus">

![English: "3 sessions today" above a Start button][shot-guide-i18n-en]

</figure>
</div>

`focus.text("start")` is a label that follows the current language.
`tl!(focus, "sessions", "count" => count.get())` also follows `count`: the
arguments are read reactively, so finishing a session changes "3 sessions" to
"4 sessions" by itself.

In a real app, keep the `.ftl` files next to your code and load them with
`include_str!`, so they ship inside the binary.

## Switch languages

Change the language at any time with `set_locale`. Every bound label updates on
the next frame, and nothing is rebuilt:

<div class="mue-demo">
<div class="mue-demo-code">

```rust
# #[cfg(feature = "i18n")]
# fn switch(i18n: &mue::i18n::I18n) -> Result<(), Box<dyn std::error::Error>> {
use mue::i18n::langid;

i18n.set_locale(langid!("zh-CN"))?;
# Ok(())
# }
```

</div>
<figure class="mue-demo-preview mue-focus">

![Chinese: the same view with 今天完成了 3 个专注时段 and 开始][shot-guide-i18n-zh]

</figure>
</div>

If a message is missing in the current language, the translator falls back to
English (`en-US`), so a half-translated app still shows readable text; give
every message an English version. The
bundled fonts must cover the language; the playground example ships Noto fonts
for Latin, Chinese, Japanese, Korean, and Arabic scripts.

## What you learned

- Fluent files hold each language's messages, including number-dependent
  forms.
- `CatalogBuilder` and `I18n` load them; a `Translator` binds messages to labels
  with `text` and `tl!`.
- `set_locale` switches languages while the app runs.
